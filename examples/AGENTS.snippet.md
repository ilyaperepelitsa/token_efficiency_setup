## Efficient source navigation and usage reviews

- Before broad source reads for symbols, definitions or callers, use Serena's
  scoped overview/lookup/reference tools on the actual worktree. Verify one real
  relevant call per context. Parents include this rule explicitly in relevant
  worker briefs; workers verify their own access. If unavailable, report once and
  continue with targeted search and bounded reads. No mandatory index rebuild.
- Use native tools for known ranges, strings, logs, fixtures and configuration.
  Expand reads for concrete dependencies; whole-file reads require a whole-file
  need. Zero symbol references does not prove no callers if indexing is incomplete.
- During active tasks, the main session follows `codeburn-review` every 15 minutes.
  Use the supplied compact report without rescanning. Compare adjacent windows
  against comparable accepted work and CPU evidence; missing data is unmeasured.
  Keep cached input separate from writes/output; token counts are not quota or bills.
- Verify the previous adjustment took effect. Make a warranted correction at a
  safe boundary within existing authority; preserve live jobs, ownership and all
  acceptance gates. A usage table or forwarded instruction alone is not a fix.
  Record at most three short lines in the existing checkpoint: result/action/evidence.
- Keep contexts bounded using compact lane briefs and safe handoffs. Agent count
  is not CPU parallelism: one owner may queue independent admitted processes.
  No separate worker usage reviews, idle wakeups, or new monitoring agents.
- Keep provisional findings local. Promote only verified reusable lessons into
  shared instructions, with evidence and limits; do not accumulate usage diaries.

These rules do not change models, native routing, permissions or resource limits.

## Optional project memory

- If Project Memory is available, use a scoped lookup when the task depends on
  an earlier decision, convention, or handoff. Verify a real repository lookup
  before relying on it. Use Serena for symbols and current source.
- Check the cited evidence against the worktree and follow the latest supported
  decision. If evidence is missing or conflicts, say what you could establish
  and continue with the work you can verify.
- Pass only the relevant results to workers. Reuse the supplied preflight for the
  same task. Keep repository snapshots, notes and reports local.
